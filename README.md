# 🎯 Quiz System (سیستم آزمون آنلاین)

یک سیستم آزمون آنلاین ساده و منعطف که با معماری چندشاخه‌ای در گیت توسعه یافته است.

## 🌿 ساختار شاخه‌ها (Branches)
- `main`: نسخه پایدار و نهایی محصول.
- `question-bank`: مدیریت و نگهداری سوالات آزمون (`questions.js`).
- `scoring`: محاسبات و منطق امتیازدهی (`scoring.js`).
- `ui`: توسعه رابط کاربری و کنترل جریان آزمون (`ui.js`).

## 🚀 نحوه راه‌اندازی و استفاده
1. مخزن را کلون کنید:
   ```bash
   git clone <repository-url>
   ```
2. فایل `index.html` را در مرورگر خود باز کنید.
3. به سوالات پاسخ دهید و در انتها امتیاز خود را مشاهده کنید.

## 🏷️ مدیریت نسخه‌ها (Git Tags)
- `v0.1.0`: ساختار اولیه پوسته HTML.
- `v1.0.0`: نسخه کامل ادغام شده به همراه بخش سوالات، امتیازدهی و UI.

برای مشاهده تگ‌ها دستور زیر را اجرا کنید:
```bash
git tag
```

## 🐛 گزارش خطا و پیشنهادات (GitHub Issues)
اگر با باگی مواجه شدید یا پیشنهادی برای افزودن کوییزهای جدید دارید:
1. به تب **Issues** در ریپازیتوری گیت‌هاب بروید.
2. بر روی **New Issue** کلیک کنید.
3. برای گزارش باگ از لیبل `bug` و برای پیشنهادات از لیبل `enhancement` استفاده کنید.
